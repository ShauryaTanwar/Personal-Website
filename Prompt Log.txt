GitHub Pages changes the setup in one important way: **you cannot run the included `/api/spotify-recent.js` serverless function on Pages**, because Pages only serves static files. GitHub Secrets are safe inside GitHub Actions, but they cannot safely be injected into browser JavaScript—anything shipped to the browser becomes public.

The cleanest “GitHub Pages only” solution is:

**Spotify → GitHub Actions using your secrets → `spotify-recent.json` → your GitHub Pages site**

Your Spotify credentials remain private inside GitHub Actions.

You need:

`SPOTIFY_CLIENT_ID`
`SPOTIFY_CLIENT_SECRET`
`SPOTIFY_REFRESH_TOKEN`

Add them under:

**Repository → Settings → Secrets and variables → Actions**

Create each as a **Repository secret**.

Then create a script such as:

`scripts/update-spotify-json.mjs`

It reads:

`process.env.SPOTIFY_CLIENT_ID`
