SPOTIFY ATTRIBUTION ASSET
=========================

The live Music receiver is intentionally waiting for Spotify's official full
logo before it displays Spotify metadata.

1. Go to Spotify for Developers -> Design & Branding Guidelines.
2. Download the official Full Logo asset.
3. Use Spotify's official BLACK full logo on Signal Lab's light background.
4. Save the unmodified SVG exactly as:

   assets/spotify-full-logo.svg

Do not redraw, recolor, crop, rotate, stretch, or otherwise modify the logo.
The website will automatically detect the file on the next page load.
