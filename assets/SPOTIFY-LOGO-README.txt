Spotify's current Developer Design Guidelines require Spotify-provided metadata
and artwork to be accompanied by the official Spotify logo.

Before enabling the live music panel:
1. Visit Spotify for Developers -> Design & Branding Guidelines.
2. Download the official Full Logo asset.
3. Use the BLACK full logo because Signal Lab places it on a light background.
4. Save/copy the official SVG into this folder as:
     spotify-full-logo.svg
5. Do not redraw, recolor, stretch, or otherwise modify the logo.

The website intentionally refuses to display live Spotify metadata until that
file exists, so you do not accidentally publish an unattributed integration.
